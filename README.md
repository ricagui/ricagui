# Ricardo Mendes

Desenvolvedor full stack com foco em aplicações web, APIs, dados relacionais e IA integrada ao produto.

Trabalho principalmente com TypeScript/JavaScript e Python, usando React, Node.js, FastAPI e PostgreSQL. Busco manter as regras de negócio explícitas, com tratamento de erros, validação de dados e testes próximos dos fluxos importantes.

## Foco técnico

- Frontend com React e aplicações web em TypeScript.
- APIs com Node.js/Express e Python/FastAPI.
- Modelagem, migrations e persistência em PostgreSQL.
- Integração de modelos de IA como etapa de interpretação, mantendo validações e decisões críticas na aplicação.
- Uso de Claude e Codex como apoio ao desenvolvimento, revisão e documentação técnica.
